Open research resources

Code, benchmarks, datasets, and models from Algorithmic Research Group, collected here at ARG Studio.

We publish datasets, models, code, and evaluation resources to support research on how AI systems behave in practice.

These artifacts are designed to surface failure modes that emerge when models interact with tools, operate over time, and rely on retrieval, compression, and imperfect objectives.

Code & Benchmarks / 4 resources

ML Research Benchmark

Seven competition-level machine learning tasks for evaluating research agents, spanning efficient training, limited-data pretraining, model merging, compression, and mathematical reasoning. Includes a tool-using baseline agent and a separate model evaluator.

  • Baseline agent — mlrb-agent-public
  • Model evaluator — mlrb-evals-public
  • ML Research Benchmark paper

ARIA Benchmark

A toolkit for generating AI research knowledge benchmarks from Papers with Code exports and evaluating them with Inspect AI. Nine task builders cover papers, methods, datasets, research areas, and evaluation metrics.

  • AlgorithmicResearchGroup/aria-public

DeltaMLBench

A benchmark for testing whether agents can improve published machine learning work. The Inspect release includes 35 task families, feedback-visible and feedback-hidden variants, paper baselines, and an audit of submitted code and reported metrics.

  • AlgorithmicResearchGroup/DeltaMLBench
  • Paper (PDF)
  • Task papers, code snapshots, and datasets
About this resource

Neural Architecture Search

A Tiny Recursive Model that predicts NAS-Bench-201 architecture performance and guides architecture search. Includes dataset builders, training and evaluation scripts, search comparisons, and a small CPU demo.

  • AlgorithmicResearchGroup/nas-public
